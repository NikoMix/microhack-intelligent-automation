# Contoso Procurement Policy

## Purchase Requests
All software and cloud service purchases must start with a purchase request in the procurement portal. The request must include business justification, expected monthly cost, data classification, and the owning cost center.

## Security Review
Tools that process confidential or personal data require Security review before contract signature. Security checks identity integration, data residency, logging, and vendor incident notification commitments.

## Preferred Azure Pattern
When an automation can run on Azure, teams should prefer managed identity, Key Vault references, Application Insights telemetry, and least-privilege RBAC over embedded credentials or unmanaged API keys.
