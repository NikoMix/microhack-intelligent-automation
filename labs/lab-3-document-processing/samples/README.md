# Sample documents

`sample-invoice.pdf` is a small, license-free invoice generated by
`generate-sample-invoice.py` (pure Python standard library — no third-party
dependencies). Use it to smoke-test the pipeline end to end.

Regenerate it any time:

```bash
python generate-sample-invoice.py
```

It contains vendor, invoice number/date, line items, and an **Invoice Total** so the
`prebuilt-invoice` model has fields to extract and the routing logic has something to
evaluate against the confidence threshold and required fields.

> Want a richer document? The Azure samples repo hosts public invoices and receipts you
> can point the HTTP trigger at. Any PDF, JPEG, PNG, TIFF, or Office file supported by
> Azure AI Document Intelligence works.
