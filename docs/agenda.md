## Pacing guidance

- **Labs 0–2 are load-bearing.** If you're behind, cut depth in Labs 3–6, never in 0–2.
- **Lab 6** is written to run as a full hands-on *or* a guided demo if time is tight —
  it's the natural flex block.
- Every lab ends with a **"definition of green"** checklist. Use it as the gate before
  moving on, and as the place to help stragglers.
- The **evidence-awareness** callouts (📋) take seconds — mention them as you pass, don't
  stop the class to collect artifacts.

## What "Train-the-Trainer" adds

Throughout the day, each lab includes **trainer notes** ("why this lab matters") and this
kit adds a [facilitator guide](facilitator-guide.md) with timing risks, common failure
modes, talking points, and debrief questions so attendees leave able to *re-teach* it.
